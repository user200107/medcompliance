# apps/web —— 演示前端

单文件、零构建、无依赖：`index.html` 里就是 HTML + CSS + JS。
打开 http://127.0.0.1:5180 即用，不需要 `npm install`。

## 为什么不用 Vue

三个服务才是这个项目的重点，为一张演示页引入 `node_modules`（100MB+）与构建链
不划算。而且这份前端要能被"clone 下来直接跑"，零构建最符合这个目标。

产品化时换成 Vue + Vite + nginx，**接口层一行不用改**——页面只依赖三个服务的
`/api/v1/*`，没有别的契约。

## 运行

```bash
python scripts/serve.py medireg     # P1 :8011
python scripts/serve.py labelguard  # P2 :8012
python scripts/serve.py dossier     # P3 :8013
python scripts/serve_web.py         # 本页 :5180
```

页面顶部会显示三个服务的在线状态（每 15 秒探测一次 `/healthz`）。

## 一屏三块，对应的正是三个岗位

| 区域 | 调用的服务 | 演示什么 |
|---|---|---|
| P1 注册路径判定 | `POST /api/v1/classify` | 结论 + **依据链** + 已被排除的候选 + 未确认维度 + 风险偏好切换 |
| P2 标签合规审核 | `POST /api/v1/labels/review` → `.../confirm` | 逐项三态检查表 + 条款依据；草稿 → **署名确认** → 不可变快照；重复确认 409 |
| P3 卷宗一致性审查 | `POST /api/v1/dossiers/review` | 冲突两侧原值 + 归一化结果；缺项；**无法核对**的属性 |

## 三个值得在面试里点开的细节

1. **P1 的"已被排除的候选"**。多数分类工具只给结论，
   这里会显示"07 医用成像器械 因命中排除说明「超声治疗设备」被剔除"。
   ——「为什么不是它」和「为什么是它」一样是交付物。
2. **P2 的"不可判定"**。故意点"填入缺项标签"，会看到某些项是黄色的
   `undeterminable` 而不是红色 `violation`：看不清 ≠ 违规。
3. **P3 的"写法不同不算冲突"**。三份文档里 `Ø3.20 mm` / 缺省 / `Ø3.50 mm`，
   页面会指出只有第三份与第一份冲突，而 `3年` 与 `36个月` 被判为一致。
   点"修好冲突"按钮再看一次，冲突消失。

## 地址

服务地址可通过 URL 参数覆盖，便于换端口演示：

```
http://127.0.0.1:5180/?p1=http://127.0.0.1:9011&p2=http://127.0.0.1:9012&p3=http://127.0.0.1:9013
```

## 已知边界

- **JS 交互未做浏览器自动化测试**。三条 POST 路径由 `scripts/smoke_all.py` 覆盖，
  页面只是它们的薄封装。
- 没有登录态。三个服务目前都不鉴权，因此 **CORS 只放行本地演示来源**
  （`http://127.0.0.1:5180`、`http://localhost:5180`），不放开 `*`。
- 不支持图片上传（P2 的视觉抽取尚未接入）。
