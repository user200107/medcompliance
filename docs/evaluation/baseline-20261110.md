## 5. 结论与限制

- **门控（规则版）不可用，这是本轮最重要的结论。** 策略是「没有确定性否定表述就默认视为器械」，于是召回率 100% 但特异度仅 4.3%（TN=4 / FP=89）。准确率 83.6% 看似不错，可多数类基线就有 82.9%，只高出 +0.7 个百分点——**这个闸门几乎没有提供信息**。它只能拦下表述里明写「无治疗作用 / 不涉及疾病」的少数样本。要真正解决，需要语义判定（模型 + 人工复核），而不是继续加关键词。
- **端到端类别指标被抽取层卡住，n 只有 355 条**（类别范围内共 96 条）。目录已经是真实的（1917 个节点，可定类 1689 个），所以这个 0% 反映的不是判定能力，而是覆盖率不足。判定层本身的能力请用隔离实验衡量：`python scripts/eval_retrieval.py`（绕过抽取，直接检索目录）。
- 标签空间里有若干系统不产出的结论（不单独作为医疗器械、药械组合、视具体情况而定），已从指标中排除并单独计数。其中「视具体情况而定」是**官方自己不给唯一结论**——要求系统比监管机构更确定，是不公平的评测。
- 数据来源为中国食品药品检定研究院《分类界定结果汇总》与《分类目录库》，仅本地评测使用，未再分发；仓库不包含原始数据，只保留指纹与聚合指标。
